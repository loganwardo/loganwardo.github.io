Project Description

HarvestBot was an embedded systems project involving a programmable mobile robot. The robot used multiple sensors and peripherals to scan its surroundings, communicate with a computer, and respond to movement commands.

The project brought together concepts from throughout CPRE 2880 including C programming, microcontrollers, sensors, communication, and hardware control.

My Role

I worked as part of a team to develop and test the embedded software used by the robot. My work involved integrating sensor measurements, robot movement, servo control, and communication between the robot and the computer interface.

Environmental Scanning

The robot could perform a 180-degree scan of its surroundings. During a scan, the servo moved from 0 to 180 degrees in 2-degree increments.

At each position, the system collected infrared sensor data using the ADC and distance measurements using the ultrasonic PING sensor. These measurements were then sent through UART to the computer.

Robot Control

The program accepted commands through UART that allowed the robot to move forward, turn left or right, perform scans, and carry out other programmed actions.

This required several hardware systems to operate together, including the servo, infrared sensor, PING sensor, UART communication, ADC, and the robot's movement system.
