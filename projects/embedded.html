HarvestBot Autonomous Sensing Robot

Embedded Systems Final Project

C • TM4C123 • UART • ADC • Ultrasonic Sensing • Servo Control

Project Overview

HarvestBot was an embedded robotic system designed to navigate an environment while collecting sensor information about nearby objects. The project integrated multiple hardware peripherals with embedded C software to create a controllable sensing and navigation platform.

The robot communicated with an external graphical interface over UART, allowing a user to control movement, perform environmental scans, and receive sensor measurements from the robot.

System Features

  • 180-degree environmental scanning
  • Infrared object detection using ADC measurements
  • Ultrasonic distance measurement using a PING sensor
  • Servo-controlled sensor positioning
  • UART communication with an external GUI
  • Forward, reverse, and rotational robot movement
  • Fine-positioning movement controls
  • LCD system-status and battery information

My Role

I contributed to the embedded software used to integrate the robot's sensors, movement system, communication interface, and user controls. The project required coordinating several microcontroller peripherals while maintaining reliable communication between the robot and the external interface.

My work involved integrating and debugging C modules for sensor acquisition, servo positioning, UART communication, movement, and system-level operation.

Environmental Scanning

One of the primary features of the system was a 180-degree environmental scan. The servo moved the sensing system from 0 to 180 degrees in two-degree increments.

At each position, the microcontroller collected an infrared ADC measurement and an ultrasonic distance measurement. The angle, infrared measurement, and distance were then transmitted over UART to the graphical interface.

Combining the two sensors allowed the system to use infrared measurements for detecting object boundaries while using the ultrasonic sensor to estimate object distance.

Communication & Control

The robot used UART communication to receive user commands and transmit sensor information. A command-based control system allowed the external interface to request scans and control robot movement.

Commands were implemented for forward movement, fine forward adjustment, reverse movement, 90-degree turns, manually specified turns, environmental scanning, and additional robot actions.

Hardware & Software Integration

The project required several hardware and software systems to operate together. At startup, the software initialized the timer, LCD, UART interface, ADC, servo, ultrasonic sensor, and robot Open Interface.

The main control loop continuously monitored the UART interface for commands and then executed the appropriate movement, sensing, or user-feedback operation. Status information was also displayed on the onboard LCD.

Skills & Knowledge Gained

This project strengthened my understanding of embedded-system integration and microcontroller programming. I gained experience combining multiple peripherals within a single system, including ADC measurements, UART communication, servo control, ultrasonic sensing, and robotic movement.

The project also improved my ability to debug interactions between hardware and software. Coordinating sensor timing, communication, movement, and user commands required systematic troubleshooting and careful integration of independently developed software modules.
